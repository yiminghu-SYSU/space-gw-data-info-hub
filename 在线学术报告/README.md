## 初步安排

- 形式：在线学术报告与交流；
- 时间：暂定周一晚上，`19:30` 为候选时间；
- 启动原则：尽快开始，不必等全部细节确定后再启动；
- 排期方式：尽量提前一个月落实报告人并通过统一邮件通知；

## 更新说明

确认报告后，可以在本目录新建独立文件，文件名建议使用：

```text
YYYY-MM-DD-报告人-简短题目.md
```

独立页面可记录摘要、报告人简介、时间、线上会议链接和相关材料。若仓库可能公开，请勿写入不适合公开的会议口令。
