## 信息摘要

本次为期一周的活动由两个相关部分组成：面向 SpECTRE 社区的暑期学校，以及面向 SpEC、SpECTRE 和相关软件开发者的会议。暑期学校主要面向研究生、博士后和教师，通过讲座和动手实践帮助参与者安装、运行并参与开源相对论天体物理代码 SpECTRE 的开发；开发者会议则聚集正在开发 SpEC、SpECTRE 及公共模拟数据交互软件的研究人员。活动以线下方式举行，讲座提供在线直播，并为部分参会者提供有限资助。

## 主要内容

SpECTRE 暑期学校预计涵盖：

- 爱因斯坦场方程的广义调和表述；
- 广义相对论流体动力学；
- 带有限体积子单元的不连续 Galerkin 方法；
- Cauchy characteristic evolution 方法；
- 使用编码智能体辅助代码开发；
- SpECTRE 的安装、运行和开源开发实践。

SpEC / SpECTRE 开发者会议将讨论 SpEC、SpECTRE，以及用于处理公开模拟数据（例如引力波波形）的配套软件开发。

## 完整通知原文

Dear all,

Applications are now open for an upcoming workshop, “[Simulating Extreme Spacetimes with SpEC and SpECTRE II: Summer school and developers' meeting](https://icerm.brown.edu/program/topical_workshop/tw-27-ses2)”, Jul 19–23, 2027, at ICERM, Brown University, US.

The Simulating eXtreme Spacetimes (SXS) collaboration has managed the development of two distinct numerical relativity codes to enable high-fidelity simulations of compact object mergers: (i) the Spectral Einstein Code (SpEC) based on pseudospectral methods, and (ii) the open-source code SpECTRE, an hp-adaptive discontinuous Galerkin scheme for relativistic astrophysics.

Our weeklong program includes two related activities: (i) a SpECTRE community workshop and (ii) a SpEC and SpECTRE developers meeting.

Our SpECTRE workshop aims to provide graduate students, postdocs, and faculty with the tools to install, run, and contribute to the open-source code SpECTRE. The open-source code SpECTRE is a relativistic astrophysics code for simulating neutron star mergers, core-collapse supernovae, and gamma-ray bursts. Our SpECTRE workshop will include both lectures and hands-on sessions. Lecture topics will include the generalized harmonic formulation of the Einstein field equation, general relativistic hydrodynamics, the discontinuous Galerkin method with finite volume sub-cells, the Cauchy characteristic evolution method, and the use of coding agents for code development. There will also be ample opportunity for students and postdocs to interact with senior participants and lecturers of the ICERM workshop program.

The code developers' meeting will bring together researchers who are actively developing SpEC, SpECTRE, and accompanying software for interacting with publicly available simulation datasets such as gravitational waveforms.

Both events will be in-person, with streaming options available for lectures. ICERM will be able to offer limited funding for some participants.

The application deadline is February 28, 2027.
