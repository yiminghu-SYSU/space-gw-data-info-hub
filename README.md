# 空间引力波探测数据处理相关信息交流站

这个仓库用于集中整理空间引力波探测数据处理相关的信息，面向重点研发专项参与人员及相关研究人员开放协作，避免内容散落在微信群、邮件和个人转发中。

不做独立网站，也不需要安装任何软件。直接在 GitHub 中阅读和编辑 Markdown 文件即可。

## 参与维护

仓库计划向参与人员开放编辑权限。不会使用 Git 的成员也可以直接通过 GitHub 网页添加和修改文件。

详细步骤见：[修改与维护说明](CONTRIBUTING.md)。新增内容可以复制使用：[通用信息模板](模板/通用信息模板.md)。

## 整理原则

- 招聘和会议信息建议同时保留简要总结和完整通知原文；
- 来源、截止日期和联系方式尽量完整；
- 已过期内容从当前列表移到相应目录的“已过期”部分，不必删除；
- 账号、密码、未公开会议链接和其他敏感信息不要放进 GitHub；
- 内部资源只提供入口，需要时在相应网络环境中查看。

> 本仓库由重点研发专项参与人员及相关研究人员共同维护，欢迎通过直接编辑或 Pull Request 补充信息。
