可以把邮件或招聘公告原文直接复制到独立 Markdown 文件中。请在文件开头补充：

- 截止日期；
- 招聘机构；
- 职位类型；
- 原始来源；
- 联系方式。

申请前请以招聘机构的原始通知为准。
